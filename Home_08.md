# Задача 1
 
Для мультипликативной группы поля $GF(5^2)$, считая $x$ примитивным элементом, определить порядки всех элементов поля.

## Теоретическая основа

Поле $GF(5^2)$ содержит $25$ элементов.  
Мультипликативная группа $GF(5^2)^\times$ состоит из $24$ ненулевых элементов и является циклической группой порядка $24$, порождённой примитивным элементом $x$:

$$
GF(5^2)^\times = \{1, x, x^2, \dots, x^{23}\}.
$$

Порядок элемента $x^k$ (где $k = 0, 1, \dots, 23$) вычисляется по формуле:

$$
\operatorname{ord}(x^k) = \frac{24}{\gcd(k, 24)},
$$

где $\gcd(k, 24)$ — наибольший общий делитель чисел $k$ и $24$.

# Задача 2

Для кодера (15,4)-кода с проверочным полиномом $h(x) = 1 + x + x^4$, описать смену состояний регистра при начальном заполнении 0 0 1 1.  
- Убедиться, что это код максимальной длины.  
- Определить минимальное расстояние этого кода.

## 1. Общие сведения о коде

- Это код максимальной длины (maximum-length code, также известен как симплекс-код или дуальный код Хэмминга).
- Параметры: $[n=15,\ k=4,\ d]$ над $\mathrm{GF}(2)$.
- Проверочный полином $h(x) = 1 + x + x^4$ — примитивный над $\mathrm{GF}(2)$.
- Поле $\mathrm{GF}(2^4) = \mathrm{GF}(16)$ строится по модулю $h(x)$, примитивный элемент $\alpha$ удовлетворяет $\alpha^4 = \alpha + 1$.
- Длина $n = 2^4 - 1 = 15$.

Кодер реализуется с помощью LFSR (линейного регистра сдвига с обратной связью) длины 4.  
Обратные связи определяются коэффициентами $h(x)$: обратная связь от 4-й и 1-й ячеек (на $x^4$ и $x$).

Обозначим регистр как четыре ячейки: [m₃ m₂ m₁ m₀] (m₀ — выходной бит, самый правый).

Начальное состояние: $0\ 0\ 1\ 1$ → [0 0 1 1].

- Выход = текущий бит m₀.

- Регистр сдвигается вправо.

### Вывод по периодичности
Регистр прошёл ровно 15 различных ненулевых состояний и вернулся в исходное.  
Ни разу не попал в состояние 0000.  
→ Это m-последовательность (максимальной длины).  
Следовательно, кодер генерирует код максимальной длины.

## 3. Параметры кода и минимальное расстояние

Это дуальный код коду Хэмминга $(15,11,3)$, то есть симплекс-код с параметрами:

- $n = 15$
- $k = 4$
- $d = 2^{4-1} = 8$

Минимальное расстояние $d_{\min} = 8$.

Обоснование:
- Все ненулевые кодовые слова имеют одинаковый вес $2^{m-1} = 8$.
- Код equidistant (равноудалённый): расстояние между любыми двумя различными кодовыми словами равно 8.
- Код содержит $2^4 = 16$ слов: нулевое + 15 слов веса 8.

## 4. Итог

- При начальном заполнении 0011 регистр проходит все 15 ненулевых состояний → код максимальной длины подтверждён.
- Минимальное расстояние кода равно 8.
